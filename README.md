# QuickVisit – Explore Before You Visit

QuickVisit is a simple and responsive company exploration website designed to help users discover company information, office locations, and contact details before planning a visit.

## 🚀 Features

* Explore company information.
* Search companies by name and location.
* Filter companies by category.
* View detailed company information.
* Navigate to company locations using Google Maps.
* Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
QuickVisit/
│
├── index.html

```

## ⚙️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the website.

## 🎯 Project Purpose

This project was developed as a personal frontend development project to practise HTML, CSS, JavaScript, responsive design, and DOM manipulation.
